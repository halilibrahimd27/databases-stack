Tek seferlik güvenlik kurulumu

Bu adımdan sonra tarayıcı uyarısı tamamen kalkar.

Tarayıcı neden “Güvenli değil” diyor?

Bağlantınız şifreli — sorun şifrelemede değil, kimin imzaladığında. Bu sunucu iç ağda çalışıyor ve bir alan adı yok; alan adı olmadan Let's Encrypt gibi kamuya açık bir sertifika sağlayıcısı sertifika veremez.

Bu yüzden kurulum sırasında sunucu kendi sertifika otoritesini üretti. Tarayıcınız bu otoriteyi henüz tanımıyor, o yüzden uyarıyor. Aşağıdaki dosyayı bir kez kurduğunuzda tanıyacak ve uyarı bir daha çıkmayacak.

1. Sertifikayı indirin

Sertifikayı indir (ca.crt)

Bu dosya yalnızca ortak anahtar içerir — gizli bir şey değildir, paylaşmak güvenlidir. Özel anahtar sunucuda kalır ve hiçbir zaman gönderilmez.

2. Bilgisayarınıza kurun

Windows
  1. İndirdiğiniz ca.crt dosyasına çift tıklayın.
  2. Sertifikayı Yükle… → Yerel Bilgisayar → İleri.
  3. Tüm sertifikaları aşağıdaki depoya yerleştir → Gözat → Güvenilen Kök Sertifika Yetkilileri → Tamam → İleri → Son.
  4. Tarayıcıyı tamamen kapatıp yeniden açın.

Firefox kendi deposunu kullanır: Ayarlar → Gizlilik ve Güvenlik → Sertifikalar → Sertifikaları Görüntüle → Yetkililer → İçe Aktar.

macOS
  1. ca.crt dosyasına çift tıklayın; Anahtar Zinciri Erişimi açılır.
  2. Sertifikayı Sistem anahtar zincirine ekleyin.
  3. Sertifikaya çift tıklayın → Güven → “Bu sertifikayı kullanırken” → Her Zaman Güven.
  4. Tarayıcıyı yeniden başlatın.

Terminalden: sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.crt

Linux (Ubuntu / Debian) 
sudo cp ca.crt /usr/local/share/ca-certificates/databases-stack.crt
sudo update-ca-certificates

Chrome/Chromium ve Firefox kendi depolarını kullanır; tarayıcı ayarlarından “Yetkililer” bölümüne ayrıca eklemeniz gerekebilir.

Android / iOS

Android: Ayarlar → Güvenlik → Şifreleme ve kimlik bilgileri → Sertifika yükle → CA sertifikası.

iOS: Dosyayı Safari ile indirin → Ayarlar → Profil İndirildi → Yükle. Ardından Ayarlar → Genel → Hakkında → Sertifika Güveni Ayarları bölümünden bu sertifikayı etkinleştirin (bu ikinci adım şarttır).

3. Panele girin

Sertifikayı kurduktan sonra tarayıcıyı yeniden başlatın ve devam edin:

Yönetim paneline git

Kurmak istemiyorsanız uyarı ekranında Gelişmiş → Devam et diyerek de girebilirsiniz. Bağlantı yine şifrelidir; yalnız tarayıcı her seferinde uyarır.
